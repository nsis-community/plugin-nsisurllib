# NsisUrlLib plug-in for NSIS

![Release](https://img.shields.io/github/v/release/nsis-community/plugin-nsisurllib?style=for-the-badge)
![CI](https://img.shields.io/github/actions/workflow/status/nsis-community/plugin-nsisurllib/ci.yml?style=for-the-badge)

This repository mirrors the NsisUrlLib plug-in, which was previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/). Its source code was never published or is lost, so this repository ships the original DLL unchanged. Nobody can rebuild, audit or fix it, or port it to other targets.

**Are you the author, or do you have the source?** [Open an issue](https://github.com/nsis-community/plugin-nsisurllib/issues/new): with the source, this repository can build the plug-in instead, or be transferred to you.

## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-nsisurllib/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `NsisUrlLib.dll` to `Plugins/<variant>/`.
